---
title: "Marius"
---

**Marius** is the set of applications through which operators receive and execute tasks dispatched by an agent

<Frame>
  ![Operator Tool](/images/operator-tool.png "Operator Tool")
</Frame>

Key definitions:

- **Agent**: Agent AI model that directs its own processes and tool use when accomplishing a task
- **Operators:** Human agents that execute tasks
- **Operator tool:** Tools that route tasks to operators
- **Marius:** The set of applications through which operators receive and execute tasks dispatched by an agent
