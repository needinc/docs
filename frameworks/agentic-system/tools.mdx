title: "Tools"
---

**Tools** give agents capabilities to observe and interact with the world

![Image](/images/image-8.png "Image")

**Definition**

- **User data tools**: tools that retrieve and update user-specific data<br />E.g., patient profiles, medical history, preferences, symptoms, or prior interactions
- **Knowledge tools**: Tools that retrieve and update knowledge<br />E.g., node map, internal playbooks, clinical guidelines, research papers, or drug databases
- **Computation tools**: Tools that calculate, analyze, or transform information<br />E.g., data analysis, running inference on TSM
- **Command tools**: Tools that trigger commands in software systems<br />E.g., call another agent, execute code, send Kakao message, appointment booking, or stable coin payment to a Halo
- **Operator tool**: Tools that route work to operators<br />E.g., Halo review, nurse escalation, beam assignment, internal operator assignment, or approval requests
- **Learning tool**: Tools that enable the improvement of the agentic system<br />E.g., Agent trace visibility tool, session replay, prompt update tool, rubric generation tool, <br /> <br /><br />
