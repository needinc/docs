**Sidney** is the set of applications through which developers design and engineer the agentic system

![Image](/images/image-6.png "Image")

**Definition**

- **Developers**: Need humans which design and engineer the agentic system
- **Developer product interface (Sidney)**: The set of applications through which developers design and engineer the agentic system
- **Agentic system**: A system of AI agents that drives the product with supporting systems<br />
